# Support Bot — бот техподдержки для Telegram

Бот принимает обращения пользователей и передаёт их менеджерам. Переписка идёт через бота, поэтому клиенты не видят личные аккаунты сотрудников.

**Стек:** Python 3.11+ · aiogram 3 · MongoDB (асинхронный PyMongo) · APScheduler

## Возможности

**Пользователь**
- создаёт обращение: тема и описание. Активным может быть только одно обращение;
- переписывается с менеджером: текст, фото, видео, документы, голосовые, стикеры;
- закрывает обращение и смотрит историю своих обращений;
- читает FAQ.

**Менеджер**
- получает уведомление о новом обращении и принимает его кнопкой. Принятие атомарное: двое не возьмут одно обращение;
- видит очередь, текущее обращение и историю переписки;
- возвращает обращение в очередь или закрывает его;
- ищет пользователя по ID, @username или ссылке t.me, может выдать мут или бан.

**Администратор** (ID указываются в .env)
- всё, что умеет менеджер;
- панель /admin: статистика, менеджеры, таймеры, приветствие, обязательная подписка на канал, FAQ, рассылка, очистка старых данных.

**Автоматика**
- менеджер не ответил за release_hours часов — обращение возвращается в очередь;
- в обращении нет активности close_hours часов — оно закрывается;
- закрытые обращения старше retention_days дней удаляются каждый день в 04:00.

## Установка (Windows 10 + VS Code)

1. Установите **Python 3.12** с python.org. При установке отметьте «Add python.exe to PATH».
2. Проверьте, что MongoDB запущен: в services.msc должна работать служба **MongoDB Server** (адрес localhost:27017).
3. Откройте папку support_bot в VS Code, затем терминал: **Terminal → New Terminal**.
4. Выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

   Если PowerShell пишет, что выполнение сценариев отключено, выполните команду ниже и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

5. Откройте .env и заполните:
   - BOT_TOKEN — токен от @BotFather;
   - ADMIN_IDS — ваш Telegram ID. Его можно узнать у @userinfobot или командой /id в боте. Несколько ID пишутся через запятую.
6. Запустите бота:

```powershell
python -m bot
```

   Можно и через **F5**: конфигурация «Run bot» уже есть в .vscode/launch.json. Сначала выберите интерпретатор из .venv: Ctrl+Shift+P → Python: Select Interpreter.

## Первые шаги

1. Напишите боту /start. Администратор сразу увидит меню сотрудника.
2. Чтобы назначить менеджера, нажмите «Найти пользователя», введите его ID или @username и нажмите «Сделать менеджером». Пользователь должен хотя бы раз нажать /start.
3. Чтобы включить обязательную подписку, добавьте бота администратором в канал. Затем откройте /admin → «Подписка на канал» → «Указать канал» и перешлите боту любой пост из канала.

## Структура

```
support_bot/
├── .env.example          пример настроек (копируется в .env)
├── requirements.txt      зависимости
├── .vscode/launch.json   запуск по F5
└── bot/
    ├── __main__.py       точка входа
    ├── config.py         чтение .env
    ├── logger.py         логи в консоль и в logs/bot.log
    ├── texts.py          все тексты бота
    ├── utils.py          вспомогательные функции
    ├── scheduler.py      фоновые задачи
    ├── db/               подключение к MongoDB и репозитории
    ├── keyboards/        клавиатуры и callback-данные
    ├── filters/          фильтр по ролям
    ├── middlewares/      пользователь, бан, подписка
    ├── services/         логика обращений, рассылка, задачи
    └── handlers/         обработчики (common, faq, user, staff, admin)
```

## Безопасность

- Секреты хранятся только в .env, и этот файл уже добавлен в .gitignore. **Никогда не коммитьте .env.**
- Для продакшена включите в MongoDB авторизацию и укажите логин и пароль в MONGO_URI.
